# Tech4Change

Site simples de anotações no GitHub Pages.

## Como funciona

1. Coloque arquivos `.md` ou `.txt` em qualquer pasta do repositório (ex.: `aulas/`).
2. Faça push para `main`.
3. A página lista e mostra o conteúdo automaticamente.

Imagens na mesma pasta do `.md` funcionam com caminho relativo:

```md
![Mapa de empatia](mapa de empatia.jpeg)
```

## Ativar o GitHub Pages

No repositório: **Settings → Pages → Build and deployment**

- Source: **Deploy from a branch**
- Branch: `main` / `/ (root)`
